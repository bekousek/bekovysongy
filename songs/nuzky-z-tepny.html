Nůžky z tepny

Minikapela

Když jsi zas C rozházenej, 
jako seno po poli,
F druhej, jak světová válka,
C vyřízenej, jako žádost, 
F vylitej, jak váza.

A C zlomenej, jak puška,
vorvanej, jak rybíz, 
F vyndanej, jak chleba z tašky,
G mrtvej, jako Havel.

Když jsi zas sundanej, jak prádlo,
strhanej, jak angreš,
zťatej, jako Záviš z Falkenštejna,
divnej, jako Brno.

Smutnej, jako zůstatek
A napjatej, jak rozpočet
Vyfluslej, jak žvejka,
Celkově špatnej, jako vodhad.
