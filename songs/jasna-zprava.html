Jasná zpráva

Olympic

G Skončili jsme jasná zpráva,  
Emi proč o tebe C zakopávam D dál,  
Ami projít bytem C já abych se G bál.  
G Dík tobě se vidím zvenčí,  
Emi připadám si C starší menší D sám,  
Ami kam se kouknu, C kousek tebe G mám.
