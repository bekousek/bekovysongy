Nastavení editoru

Pro ukládání změn potřebuješ GitHub fine-grained Personal Access Token omezený jen na tento repozitář (ne classic token se scope repo — ten dává přístup ke všem tvým repozitářům).

Vytvoříš ho na github.com/settings/personal-access-tokens/new. Nastav: Repository access → Only select repositories → bekousek/bekovysongy, a v Permissions → Repository permissions vyber Contents: Read and write. Nic dalšího není potřeba.

Token se uloží jen v tomto prohlížeči (localStorage).
